# agristudent-bd
## Faculty bulk upload

Admin → Faculty now includes **Bulk Upload Faculty from Sheet**. Supported formats are CSV, XLSX, and XLS. Use the built-in template. Required columns: `name`, `department`, `courseCodes`; optional columns: `designation`, `photoUrl`. Course codes may be separated by commas, semicolons, pipes, or line breaks. Duplicate name+department rows are skipped. Admin bulk uploads are written as approved faculty records.
