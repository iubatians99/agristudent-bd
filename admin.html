📦 Bulk Upload Terms

Add many terms at once. Everything you add here is previewed first, and only published to the Knowledge Hub as approved once you hit Upload.

How it works

Upload a .csv, .xlsx or .xls file with one term per row. The first row must be the column headers. Recognised columns (any order, capitals don't matter):

  • name — the term (also accepts term / title) — required
  • description — the meaning (also accepts definition / details)
  • image — an image link, or the filename of an image you pick below (also accepts imageUrl / photo)

Image links are pulled in for you — no need to download anything first. If your sheet lists filenames instead (like rhizobium.jpg), just pick those images in the box underneath and they'll be matched up by name.

Only needed if the image column holds filenames rather than links.
Each image becomes one term — the filename is used as a starting name, which you can edit below.

📊 Bulk Upload Faculty from Sheet

Upload a CSV, XLSX or XLS sheet. Required columns: name, department, courseCodes. Optional: designation, photoUrl. photoUrl accepts a direct image URL or a Google Drive share/view link (set the Drive file to “Anyone with the link” → Viewer).

📚 Course Suggestions — Awaiting Review

Students can suggest a missing course code from a faculty's profile page. Approving links the code to that faculty immediately; rejecting discards the suggestion.

⭐ Faculty Reviews — Moderation

Signed recommendations (student's own name) go live automatically. Anonymous ones land here first — approving one publishes it and adds it to that faculty's public rating; rejecting one deletes it, so it never affects the public score.
